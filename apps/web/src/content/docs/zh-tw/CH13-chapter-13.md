# 場面調度：空間、動線與視線

> 編輯狀態：研究草稿；英文稿為工作對譯。章名、術語、來源定位、電影案例及插圖均待人工審查，不得視為出版核准。

<a id="CH13-S00"></a>
## 本章導讀
本章把場面調度視為可分析、可排演、可交接的空間設計：從戲劇目標出發，安排人物、物件、視線與攝影機，再用連戲、安全及可行性檢查修正。AI 僅提供待審草案，不能替代片場決策。

<a id="CH13-S01"></a>
## 學習目標與適用對象
完成本章後，讀者能：（1）將場面調度拆解為場景、道具、服裝、光線、表演與鏡頭可見空間；（2）繪製平面走位圖並標示演員路徑、視線、攝影機與遮擋；（3）說明空間安排如何支持或改變敘事資訊與人物關係；（4）以連戲紀錄檢查鏡頭間的方向和位置；（5）將場面目標轉為可檢查的 AI 視覺提示。適用於導演、攝影、美術、分鏡、剪輯及生成式影像學習者。先備知識：鏡頭景別、構圖、軸線與基本分鏡概念（參見 CH02–CH04）。

<a id="CH13-S02"></a>
## 先備知識
先能辨認場景與鏡頭的差異、畫面內／外空間、視線方向、動作連續性及基本場記欄位。若尚未掌握 180 度軸線，不必先追求複雜走位；先以單一入口、兩名表演者和一個攝影機位置練習。術語是工作定義，須由繁中編輯及電影專業審校確認。

<a id="CH13-S03"></a>
## 核心術語
| 術語 | English | 本章工作定義 |
|---|---|---|
| 場面調度 | mise-en-scène | 鏡頭中可見元素及其安排；不同理論傳統對範圍界定不盡相同。 |
| 走位／調度 | blocking | 表演者在空間中的位置、移動路徑與彼此關係。 |
| 視線軸 | eyeline | 角色注視方向形成的畫面關係；須配合鏡頭位置建立可讀性。 |
| 畫面內／外空間 | on-screen / off-screen space | 畫框內可見區域與由聲音、視線、出入口或剪接暗示的畫框外區域。 |
| 遮擋 | occlusion | 前景或其他物件遮住部分人物／空間，使資訊延後、受限或重新分層。 |
| 連戲 | continuity | 相鄰鏡頭在空間方向、動作、道具和視線等方面維持可理解的關係。 |

對應草案 ID：TERM-CH13-MISE-EN-SCENE、TERM-CH13-BLOCKING、TERM-CH13-EYELINE、TERM-CH13-OFFSCREEN-SPACE、TERM-CH13-OCCLUSION、TERM-CH13-SPATIAL-CONTINUITY。

<a id="CH13-S04"></a>
## 歷史與基本原理
「mise-en-scène」源自戲劇舞台安排，電影研究常用它討論演員、佈景、道具、服裝、光線與空間如何共同構成畫面；攝影機運動、景框及焦點是否納入此概念，依作者的分析框架而異。故此處把它當作分析工具，而非唯一固定清單。Dix 將觀眾在畫面中所見與攝影機／構圖選擇放在相關但可區分的層次；Gibbs 以風格和詮釋為重點，提示元素需在整體脈絡中閱讀（R094、R095；目前僅核對出版者頁面及章節摘要，細節定位待查）。

場面調度的基本問題不是「畫面放了什麼」，而是「誰能看見什麼、何時看見、被什麼阻隔，以及觀眾如何推斷人物關係」。入口、窗、樓梯、桌面與前後景可組織權力、親密、隔離或不確定性；這些是可供分析的形式效果，不是場景元素本身自動具有的普遍意義。評讀時應指出可觀察證據，再把詮釋標示為理論／讀法。

<a id="CH13-S05"></a>
## 傳統製作方法
前期由導演與編劇確認戲劇意圖，再與攝影、美術、服裝、燈光及製片部門協作，將抽象目標轉成可拍攝的空間和資源方案。美術設計與導演／製片協調場景、預算、時程及技術可行性，工作範圍會隨製作規模變化（R096）。排演時導演與演員尋找可信且安全的動作；副導、劇本監督、攝影與美術人員依製作分工記錄位置、鏡位、視線和連戲。英國職業標準可作角色流程參考，但不能直接當成所有國家或所有劇組的法定配置（R097）。

簡易平面圖要包含：北向或方向基準、牆／入口／窗、固定家具、人物起始點與終點、路徑箭頭、攝影機／鏡頭編號、視線箭頭及不能跨越的軸線。場景有多個鏡頭時，每張圖使用同一座標和方向，並註明時間、版本及變更。排演後再確認鏡頭是否服務戲劇目標，避免先把場景拆成覆蓋鏡頭，才在剪輯中尋找關係。

<a id="CH13-S06"></a>
## AI 時代的技術轉換與限制
AI 可協助把已明確描述的場景目標轉成分鏡提案、替代構圖、物件清單或視覺連續性檢查表；也可在同一平面圖上生成不同人物路徑作為討論草案。它不能可靠地替代導演與演員協商、場地勘查、攝影機可達性、表演安全、鏡頭連戲判斷或權利審查。生成模型可能把門窗、人物朝向、手持道具和空間尺度改變；文字提示並不能保證跨鏡頭一致。

建議把輸入拆為「戲劇目標、場景幾何、人物起訖、視線、攝影限制、禁止變更、輸出格式」。把不可變的幾何資料存成結構化 JSON，將生成圖視為未核准提案。未經測試的模型能力、提示參數與可重現性都標為待驗證，不宣稱特定工具有不存在的鎖定或連戲功能。不可輸入未授權劇本、演員個資或機密場景資料至未核准服務。

<a id="CH13-S07"></a>
## 詳細工作流程
1. **寫出戲劇問題**：例如角色是否願意進入房間、誰掌握談話節奏；避免只寫「拍得有電影感」。
2. **列出空間事實**：入口、窗、障礙物、可移動家具、攝影機可達區與安全限制；未知處標記待勘景。
3. **定人物行動**：每人起點、目標、路徑、停點、視線對象及觸發行動的事件；由導演／表演者確認。
4. **選擇觀眾資訊**：哪些資訊先展示、隱藏或延遲；決定是否使用門框、前景遮擋、景深或畫外聲音。
5. **畫平面圖及鏡頭方案**：標註鏡頭位置、景別、視線和軸線；不同方案應改變敘事效果而非只換角度。
6. **排演並檢查可行性**：確認動作自然、鏡頭可拍、燈光與收音可行且不造成不安全動作。美術、攝影及製片評估成本和時間。
7. **建立連戲表**：記錄每個鏡頭開始／結束位置、手勢、道具手、視線、焦點和場景版本；劇本監督依現場流程管理。
8. **拍攝後核對**：檢視剪接是否保留方向與可讀性；若有意違反連戲規則，須明確記錄其敘事目的。
9. **AI 提案隔離**：AI 輸出只作候選圖，逐項對照幾何 JSON、人物同意、實拍條件和權利；人類選定後更新版本，不以模型輸出取代場記正本。

## 提示詞與技術參數
以下是**文字規劃提示範本**，不是特定生成工具的已驗證語法：

```text
任務：提出【鏡頭／場面調度】草案，不生成或仿製任何既有電影畫面。
戲劇目標：【角色關係／觀眾應得知或暫時不知道的事】
空間幾何：【以座標或平面圖描述門、窗、牆、固定物件】
人物：【角色代碼、起點、終點、行動、視線、停點】
攝影限制：【鏡頭位置、景別、軸線、可移動範圍】
連戲不變項：【空間方向、道具所在手、出入方向】
安全／權利限制：【演員界線、機密資料、不得引用的第三方素材】
輸出：1) 兩個不同敘事方案；2) 各方案平面圖資料；3) 連戲風險清單；
      4) 不確定項與需由導演／攝影／美術現場確認的事項。
不得編造片場尺寸、鏡頭規格或工具能力；所有假設須明確標示。
```

可用 JSON 欄位草案：`scene_id`、`revision`、`coordinate_units`、`room_bounds`、`openings[]`、`props[]`、`performers[]`、`camera_positions[]`、`eyelines[]`、`axis_id`、`constraints[]`、`source_notes[]`、`review_status`。實際資料 schema 尚待全書工程定稿；不得把此清單誤認為已發布標準。若使用圖像模型，需另外記錄供應商、模型版本、日期、提示詞、seed（若有）、輸出檔雜湊及人工修改；本章沒有呼叫圖像生成服務。

## 電影案例分析
### 《寄生上流》（Parasite, 2019）：垂直空間與可見性

Criterion 的評論文章討論半地下室與現代住宅的高低位置、窗景、階梯和地下空間，分析空間如何參與社會階序與人物行動（R098）。這是評論者對影片形式的詮釋，不等同電影主創唯一意圖，也不作社會階級的普遍定律。教學練習可畫出「街道—半地下室—上坡住宅—地下空間」的關係圖，再問：誰能從窗戶看見街道？誰控制出入口？樓梯如何改變角色移動和資訊差？本章未取得合法觀看片源或逐鏡時間碼，因此不提供時間碼，也不聲稱親自觀片驗證。

### 香妲・艾克曼的空間電影：畫外空間與時間

BFI 的評論以《房間》（La Chambre, 1972）及《旅館蒙特雷》（Hotel Monterey, 1972）討論鏡頭穿越室內、走廊與畫框外空間的方式，並把移動與時間經驗連結（R099）。這是評論分析，片名年份與分析重點應再由電影史編輯及影片版本核對。可作比較：固定鏡頭中演員離開畫面，和攝影機移動穿過門框，分別如何改變觀眾對房間外部的想像？不要把評論文章的觀點寫成普遍法則。

經典案例的使用原則：先描述畫面可觀察到的空間關係，再提出有來源支撐的解讀；觀看片源、版本及時間碼留待人工補記。案例分析與原創示意圖分開，不重製或描摹電影構圖。

## 常見錯誤與品質驗證
| 失誤 | 可觀察後果 | 驗證／改善 |
|---|---|---|
| 只用象徵詞下指令（如「壓迫感」） | 生成／設計結果無法執行或驗收 | 指定距離、遮擋、出入口、視線及觀眾資訊，再把情緒當成預期效果而非保證。 |
| 平面圖、分鏡與現場擺位不同步 | 方向、道具或鏡位互相矛盾 | 統一場景版號；變更由指定責任人更新並留變更記錄。 |
| 把視線方向當成角色心理的充分證據 | 觀眾可能讀到未被文本支持的動機 | 區分畫面事實與詮釋，檢查表演、剪輯、聲音及上下文。 |
| 過度遮擋而失去動作可讀性 | 觀眾無法理解誰做了什麼 | 用粗剪或排演測試關鍵動作是否可辨識，必要時增加揭露鏡頭。 |
| AI 圖像改變空間或人物連續性 | 門窗、左右方向、道具位置漂移 | 對照結構化空間資料與連戲表；不符合即拒收，不把畫面當製作定稿。 |
| 把「連戲」等同永遠維持連續 | 有意識的跳接或主觀視角被錯判 | 先確認是否為明確形式選擇，再檢視觀眾理解和剪輯目的。 |

最低檢查：每個主體有清楚起點／終點；每張圖有方向基準、攝影機、視線及出入口；鏡頭間人物／道具狀態可追溯；每個理論句能分辨來源事實與分析；提示詞明示假設及需人工決定項。技術驗收由劇組按實際場地、鏡頭和安全流程執行，不能只靠文件自動通過。

<a id="CH13-S11"></a>
## 練習、評量與延伸研究
**練習：**設計一段兩人於室內交換一件物品、其中一人不願被看見的 20–40 秒場面。提交一張有尺寸或比例註記的平面圖、兩種走位方案、各自 4–6 個鏡頭的分鏡文字、連戲表，以及一個供 AI 提案的結構化提示。不得使用既有電影角色、場景圖或劇照。

**評量（每項 0–2）：**空間圖可執行；人物路徑與戲劇目標連結清楚；視線／軸線可辨；觀眾資訊差有明確設計；安全及連戲變更有記錄。0=缺漏或矛盾，1=部分可讀但需大幅修正，2=可由另一組依文件排演並指出風險。此量表是教學建議，需教師試用調整。

**延伸研究：**比較固定鏡頭與移動鏡頭的畫外空間；研究不同文化脈絡中室內空間／門檻的影像解讀；測試生成式影像對人物數量、房間幾何與視線的穩定度，公布模型版本、失敗樣本及評估方法。不得以少量提示成功案例推論工具普遍可靠。
