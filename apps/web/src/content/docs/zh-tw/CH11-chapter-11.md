# 導演工作：意圖、溝通與決策

> 編輯狀態：研究草稿；英文為工作譯稿。理論、術語、電影案例、雙語文字與插圖均未取得正式出版核准。

<a id="CH11-S00"></a>
## 本章範圍與證據標記
本章討論導演如何把劇本中的戲劇意圖轉成可排演、可拍攝、可剪輯，也能由團隊共同檢查的選擇。核心不在「導演替所有部門下技術指令」，而在建立共同目標、提出清楚問題、理解專業回饋，並在時間、預算、安全、權利及表演需要之間作可追溯的決定。本章聚焦導演的工作方法，不取代演員調度（CH12）、場面調度（CH13）與分鏡預視覺化（CH14）的深入章節。

以下以標籤區分陳述性質：**已查證事實**指來源可支持的資料；**理論**指出電影研究的分析脈絡；**實務建議**是可按製作規模調整的工作方法；**AI 假設**是尚需實測的用途；**示範**則為本書自行建構的練習，不作歷史證據。DGA 資料描述特定工會協議或自願指引，並不代表所有地區、僱用關係、製作規模或合約都相同。[R078][R079]

<a id="CH11-S01"></a>
## 學習目標與適用對象
完成本章後，讀者能夠：

1. 把抽象主題或導演意圖改寫成場景目標、人物行動、觀眾可見／可聽的證據及可討論的製作選擇。
2. 區分「說明意圖」「提供參考」「提出選項」與「作成決定」，並依角色責任和製作約定留下決策紀錄。
3. 為演員、攝影、美術、聲音、剪輯及製片部門準備不同形式的簡報，而不把所有人都當成同一專業的執行者。
4. 在排演、拍攝和剪輯中收集回饋，判斷哪些變更服務故事、哪些會影響連戲、時間、資源或權利。
5. 把 AI 產生的方向、分鏡草圖或文字分析視為待查核提案，辨認其中的假設、遺漏與不可交由模型決定的事項。

**適用對象：**初學導演、短片與學生劇組、編劇、製片、攝影、美術、剪輯及使用生成式 AI 協助前期工作的影像團隊。不同市場與製作類型會採用不同職稱和權限；本章的流程範例須依實際團隊協議調整。**評量成果：**一頁導演意圖簡報、一場戲的部門交接表、一次有理由與影響範圍的決策紀錄，以及一份標明 AI 假設的預視覺化提案。

<a id="CH11-S02"></a>
## 先備知識
建議先熟悉劇本、場景、節拍、景別、鏡頭、構圖、剪輯連續性與基本片場職務。讀者可先參考 CH01–CH10；尚未熟悉鏡頭語言者，應特別回看 CH02、CH03。這些先備概念不是入門門檻：本章會在案例中重述必要的導演決策脈絡。

導演工作還需要三類非器材能力：第一，聆聽與提問，讓編劇、演員、部門主管能說明問題；第二，辨認決策的可逆性，知道哪些選擇可以在排演中再試，哪些會鎖定昂貴搭景、特效、場地或拍攝日；第三，說明取捨，讓團隊明白決定如何回應故事目標。這些是實務建議，不是所有製作都採用的正式職能標準。

**安全界線：**表演工作不得以羞辱、威脅、未經同意的身體接觸或危險行為來「逼出真實」。親密、危險、兒少、動物、特技與其他高風險場面，應依當地法規、製作規範及合格專業人員建議規劃。本章不提供法律或職安意見。

<a id="CH11-S03"></a>
## 核心概念與專業術語
本章使用以下工作定義；跨地區慣例可能不同，詞條仍待雙語專業校訂。術語 ID 是跨章引用的穩定鍵：

- [TERM-CH11-DIRECTOR](#CH11-S03)：導演（film director）。在特定製作安排中，整合故事、表演、視聽形式與協作流程的人員；不表示其對所有僱員、預算或成品都擁有不受合約限制的最終權限。[R077][R078]
- [TERM-CH11-DIRECTORIAL-INTENTION](#CH11-S03)：導演意圖（directorial intention）。對場景要讓觀眾理解、感受或期待什麼的可討論假設；應能連到具體行動或聲畫證據，而不只是一組情緒形容詞。[R077]
- [TERM-CH11-DIRECTING-BRIEF](#CH11-S03)：導演簡報（directing brief）。將故事目標、場景限制、共同語彙、待決問題和部門需求整理成可供團隊回應的文件；不是把美學命令逐項下達給所有人。
- [TERM-CH11-BLOCKING](#CH11-S03)：演員走位／場面調度（blocking）。演員相對彼此及攝影機的空間移動安排；具體走位與鏡頭設計會互相影響，詳細技法見 CH12、CH13。[R077]
- [TERM-CH11-SHOT-LIST](#CH11-S03)：鏡頭清單（shot list）。為場景與拍攝日規劃所需鏡頭的工作清單；應服務敘事和現場條件，不能取代現場判斷。[R077]
- [TERM-CH11-DEPARTMENT-HANDOFF](#CH11-S03)：部門交接（department handoff）。將一項創作目標轉成不同部門可以評估、補充或執行的資訊，同時保留彼此的專業方法。
- [TERM-CH11-DECISION-LOG](#CH11-S03)：決策紀錄（decision log）。以日期、問題、選項、依據、負責角色、影響範圍及重開條件記下重要選擇；不是完整會議逐字稿。
- [TERM-CH11-DIRECTORS-CUT](#CH11-S03)：導演剪輯版（director’s cut）。在特定製作／合約語境中，指導演剪輯階段的一種版本或權利安排；DGA 對其有特定適用條款，其他製作不可直接類推。[R078]

## 歷史與基本原理
**已查證事實與理論脈絡：**電影導演的工作並非自始至終都等同於今日常見的「一位作者統合整部電影」。Rutgers University Press 的《Directing》從默片時期一路討論導演作為藝術與職業的變化，指出電影製作制度、創作分工、工業條件及合作關係會共同形塑導演的工作。[R085] 美國國會圖書館對早期電影製作的概述也記錄了從攝影師兼製作者承擔多項工作，到編劇、導演、表演、攝影、剪輯與設計逐漸成為不同工種的歷史轉變；這是美國電影史的概述，不能直接套用到世界各地的發展。[R086]

1950 年代後，作者論（auteur theory）使研究者更集中討論導演作品中的可辨識風格與主題；其後的研究持續爭論電影作者性、產業制度與多部門共同創作的關係。Oxford Bibliographies 將「其他電影工作者的藝術性」及「協作如何建構電影作者性」列為長期研究議題；Rutgers 的導演史研究亦著重合作、妥協與工業條件。[R084][R085] 因此，本章把「導演的統合責任」當成分析與實務模型，不把電影創作簡化成單一個人的作者神話。

**基本原理：**導演需要把一個不可直接拍攝的概念，例如「人物不再相信對方」，拆解成可測試的行動、資訊差、空間距離、視線、聲音與剪接節奏，再邀請專業部門提出可行解法。意圖不是答案，而是供團隊共同工作的假設。若排演或粗剪不能讓觀眾讀出預期關係，導演要重新檢查假設、表演任務、攝影視點或場景資訊，而不是只重複抽象形容詞。

<a id="CH11-S05"></a>
## 傳統電影製作方法
AFI 對導演工作的介紹將整體創意方向、與演員工作、以及和攝影、美術、剪輯、編劇、製片等部門主管協作列為主要面向。[R077] 導演並不是只在拍攝現場喊「開始」和「停」；很多決策在劇本研讀、選角、勘景、排演、視覺設計、拍攝計畫與後期流程中逐步形成。DGA 對特定會員協議的說明亦把準備、拍攝與後期的創意參與納入協議範圍；其權利只適用於符合該協議的工作，不可當作普遍法律規則。[R078]

**實務流程（可依規模裁剪）：**

1. **讀劇本與確認核心問題：**以人物目標、阻力、選擇和代價拆解場景；列出尚未解答的故事問題，不急著先決定器材。
2. **建立共同意圖：**用一段簡短文字描述觀眾在場景前後應知道或感受到的差異，並列出可見、可聽的證據。
3. **與編劇及製片討論：**確認版本、創作範圍、時間、成本、權利、檔期與必須保留的資訊。合約權限以實際文件為準。
4. **與演員排演：**給予角色目標、對手行為、場景事實和可行動的任務；讓演員提出讀法，再用排演檢查文本是否成立。不要把心理診斷或情緒標籤當成唯一指令。
5. **跨部門簡報：**攝影、美術、服裝、聲音、剪輯和製片各自需要不同問題與交付物；讓部門主管提出替代方案與風險。
6. **做拍攝計畫：**場景拆解、走位、鏡頭清單、排程、交通、道具、連戲、聲音和安全計畫彼此對照。導演與第一副導、攝影指導及其他主管的工作分工依專案慣例而定。
7. **現場驗證：**檢查演出、畫面與聲音是否傳遞目標，記錄未解問題及需要補拍的素材；現場改動須同步告知受影響部門。
8. **後期回看：**透過 dailies、粗剪、試映或其他適用方式，確認觀眾是否能讀懂資訊與情感轉折；對需改動的選擇留下版本與理由。

DGA 的 Code of Preferred Practices 明確將其自身列為自願指引，並提出例如盡早讓導演參與、避免不必要壓縮準備／剪輯時間等建議；這些不是適用所有製作的規則。[R079]

## AI 時代的技術轉換與限制
**實務建議與待驗 AI 假設：**文字模型可以協助把導演簡報拆成問題清單、產生不同的場景讀法、檢查文件是否遺漏欄位，或把已核准的場景資訊整理成部門交接表。這些用途是工作假設與提示詞範例，不代表任何特定產品已具備相同功能，也不代表模型理解表演、政治脈絡、文化脈絡或導演意圖。開始前應查核該工具當前官方文件、資料使用條款與版本，並用本組素材實測。

生成圖像、分鏡或預視覺化可用來討論構圖、場景方向及替代方案，但生成結果可能改寫角色外觀、忽略場地連續性、虛構不存在的道具，或沿用帶有權利風險的視覺特徵。AI 產物不能當成已核准的演員、佈景、鏡頭、拍攝安全方案或正式圖稿。若需真實演員影像、劇本、未公開企劃或客戶資料，先取得製作授權並檢查服務條款及資料保留方式；不能把機密內容直接貼入未核准服務。

建議採用「人類設定目標—模型提案—團隊質疑—實物排演／技術測試—人類決策—留存版本」的閉環。模型輸出要標示為草案，保留輸入檔版本、生成時間、模型／工具版本（若可取得）、使用者修改與採納理由。模型不可代替導演與演員建立同意、判斷倫理、選擇表演邊界或承擔現場安全責任。尤其不可用 AI 的臉部情緒分類或文本推論，對演員心理狀態作診斷。

## 詳細工作流程
以下是可以套用於短片、廣告、紀錄片或長片前期會議的本書工作模型。它不是法定標準；遇到紀錄片倫理、品牌審核、工會條款或場地規範時，須增加相應審查。

1. **凍結輸入版本：**指定劇本版本、頁面／場景編號、相關參考和決策人；未核對版本的筆記不得當作現行指令。
2. **寫場景命題：**用一至兩句說明角色目前追求什麼、什麼阻礙他，以及場景結束時哪項關係／資訊改變。
3. **提出觀眾證據：**列出觀眾在畫面、聲音、表演或剪接中能觀察的證據；再寫一個「若觀眾沒讀到」的替代解法。
4. **排演與傾聽：**讓演員按任務試演；導演記錄有效的動作、節奏、停頓和意外發現，不先把每個反應鎖死。
5. **跨部門提案：**請部門主管提供至少一個符合意圖的做法、一個風險／成本提醒，以及一個可供比較的替代方案。
6. **評估約束：**檢查安全、同意、場地、預算、時間、連戲、聲音、權利、可及性及後期需求。
7. **選擇並記錄：**記下採用方案、未採用方案及理由、決策人、受影響場景／部門、需更新的文件和重新討論條件。
8. **現場快速對焦：**用共同語句確認今天的故事目標和不可漏拍資訊；即時更改需讓相關主管知情。
9. **回看素材：**導演與剪輯師先檢查資訊清楚度、表演連續性、視點與聲畫關係，再討論風格細節。
10. **版本封存：**將最新版簡報、鏡頭清單、場記／連戲資料和決策紀錄一起標版本，避免舊指令仍留在現場流通。

## 提示詞與技術參數
以下模型中立提示詞只用於生成「可供人員討論的提案」。不要要求模型替導演作最終決定；輸出中的電影事實、演員資訊、製作規格、合約或權利主張均須另行查證。

**提示詞範本：導演意圖轉成部門討論提案**

    角色：前期製作研究助理。
    權限：不是導演，也沒有核准權。
    輸入：只使用已核准的劇本版本與場景摘要。
    不得補造事實、器材、地點或工具功能。
    目標：[人物目標／阻礙／結尾變化]
    意圖：[觀眾知情／感受／期待]
    限制：[時長／場地／演員／預算／拍攝日]
    安全：[同意與界線]
    任務：提出三個不同的討論方案。
    各列觀眾證據、演員任務、攝影美術問題、
    聲音剪輯效果、風險與仍需人類決定的事項。
    假設標示「未核實」；資料不足時先提問。
    附劇本版本與場景 ID。輸出 Markdown 或 JSON。
    最後列出輸入、模型提案及未核實內容。
  
  **可重現記錄欄位：**工具與模型版本、日期、提示詞版本、輸入資料雜湊、溫度／種子等可取得的設定、輸出檔雜湊、人工修改、採納／捨棄原因。不同服務提供的控制參數並不一致；不得假設所有模型都支援 temperature、seed、固定版本或可重現輸出。沒有實測時請寫「未測」。

## 電影案例分析
### 《教父》（The Godfather，1972）：把戲劇意圖轉成聲畫層次

**已查證片目事實：**AFI Catalog 記載電影由 Francis Ford Coppola 執導，Mario Puzo 與 Coppola 編劇，Gordon Willis 擔任攝影指導，Dean Tavoularis 負責製作設計；片目亦整理該片與 Puzo 小說的關係及製作史料。[R082] 這些片目資料能確認署名和可追查脈絡，不足以單獨證明某位創作者的主觀意圖。

**有來源的製作／形式描述：**ASC 重刊 1971 年《American Cinematographer》對 Willis 的訪談，記錄他談到拍攝此片時如何追求機械上簡單、保留場景原有特性的攝影方法，並提及他與 Coppola 的共同方向。[R083] ASC 的另一篇文章描述電影開場 Bonasera 陳述時，攝影機由緊密特寫慢慢拉遠，逐步揭露 Corleone 辦公室及 Don 的側面；文章指出導演與攝影指導原先設定的「不使用變焦」原則在此處例外一次，並將此選擇連到人物介紹與資訊延宕。[R081] 以上是已刊文章中的描述，不是本章作者對某一修復版逐格觀片的紀錄；本稿不提供時間碼。

**本章的形式分析：**把「權力暫時不完全可見」作為可討論的導演意圖假設，再看焦點距離、資訊揭露節奏、光線可見度、人物進出與演員語速如何共同建立觀眾的觀看位置。這是依據來源材料所作的分析，不宣稱只有一種正確解讀，也不把攝影師工作歸給導演一人。該案例能示範的是「共同目標可以讓特例有理由」，不是「永遠不變焦」或「黑暗就等於權力」的通則。

**原創轉化練習：**另設一個新故事：公寓管理員在夜間收到住戶的緊急請求。只借用抽象操作「先讓觀眾聽見請求，再逐步揭露接收請求者的地位和環境」，不得複製 Corleone 辦公室、人物、服裝、構圖、演員臉孔或原片鏡頭。小組各做一版：固定鏡頭版、聲音先行版、人物移動揭露版。比較觀眾理解時間、人物權力與表演空間，再記錄新版本如何形成自己的視覺設計。不得以「致敬」名義仿製可辨識場面。

**觀片待辦：**編輯或作者須指定合法觀看版本、發行／修復資訊、觀看來源、觀察者及時間碼，補上自身觀片記錄；若無法取得合法版本，保留以上公開來源分析並明確排除鏡頭級新增主張。

## 常見錯誤與品質驗證
| 常見錯誤 | 可觀察的問題 | 修正與驗收方法 |
|---|---|---|
| 意圖只有形容詞 | 「更有電影感」「更悲傷」無法指向場景行動 | 寫出人物行動、資訊變化與聲畫證據；請不同部門用自己的話複述 |
| 把偏好誤當成故事需求 | 因為喜歡某鏡頭／器材而忽略場景目的 | 比較至少兩個形式方案；說明每方案帶來及犧牲什麼 |
| 對演員只下情緒指令 | 演員只能模仿外顯表情，缺乏可行動任務 | 換成對手、目標、阻力、策略或具體事件；以排演回看效果 |
| 導演以為所有人已收到改動 | 部門依據不同劇本或舊版簡報執行 | 檢查檔名、版號、變更標記及收件角色；現場變更記錄責任人 |
| 會議結論沒有可重開條件 | 方案變更時無法追溯決策脈絡 | 記錄依據、影響範圍、期限和觸發重新討論的條件 |
| AI 輸出被當成事實或核准 | 來源、可行性、安全、同意或權利未查核 | 逐項標示模型建議；由相應主管確認；未查核者不得進入拍攝通告或正式資產 |
| 過度增加設計元素 | 服裝、鏡頭、聲音和燈光互相競爭 | 依場景目標減法測試；逐一移除元素，看觀眾理解是否變差 |

**章節級品質檢查：**劇本版本與場景 ID 是否明確？角色目標和觀眾資訊是否可說明？部門交接是否能轉成具體問題？安全與同意邊界是否交由合格人員確認？選擇是否留有理由、版本、負責人和後續影響？AI 輸出是否標成未核實？案例來源是否只支持其實際描述範圍？任一「否」都應回到前期修訂，不能以本章 checklist 代替現場專業判斷。

## 練習、評量與延伸研究
### 練習：導演意圖工作包

選一段自寫或已獲授權使用的 1–2 頁劇本，不使用未授權劇本全文。小組完成：

1. 一段不超過 80 字的場景命題；列出角色目標、阻礙、轉變及觀眾需要知道的資訊。
2. 兩種不同的表演任務描述，並說明如何尊重演員的選擇與安全界線。
3. 一頁導演簡報：核心意圖、觀眾證據、色調／節奏參考的文字描述、待部門共同解決的問題。
4. 交接給攝影、美術、聲音、剪輯和製片各一個具體問題；請部門同學提出可行方案和風險。
5. 排演或用紙上預視覺化比較兩種場景處理方式，寫一份決策紀錄及一項重新開啟決策的條件。
6. 若使用 AI，保存提示詞與輸出雜湊，標示未核實主張，並列出至少三項由人類修正或拒絕的建議。

### 評量規準（每項 0–2 分，共 10 分）

- **故事可讀性：**0 無清楚目標；1 目標存在但觀眾證據模糊；2 目標、阻力與轉變可在場景中觀察。
- **溝通可執行性：**0 只有風格形容詞；1 部分部門有明確問題；2 多部門可以各自提出專業方案並回應共同意圖。
- **協作與表演倫理：**0 缺少聆聽或安全界線；1 有提及但未納入流程；2 有排演回饋、同意／安全檢查和責任人。
- **決策追溯：**0 無版本或依據；1 記錄方案但未列影響；2 留有版本、依據、影響角色、待辦及重開條件。
- **AI 素養與來源：**0 把模型輸出當事實；1 有部分查核；2 清楚區分輸入、模型建議、來源事實與未核實項目。

分數只評量本次工作包，不代表作品藝術品質。延伸研究可比較不同製作制度的導演權限、默片到有聲片的分工變化、作者論與集體作者研究，以及 AI 預視覺化如何改變演員／部門參與；須納入不同國家、語言、產業與性別／族群視角，不以好萊塢單一制度代表所有電影製作。
