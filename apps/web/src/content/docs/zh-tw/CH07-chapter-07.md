# CH07｜人物、欲望、衝突與角色弧線
> 狀態：研究草稿；繁中為工作主稿，英文為工作對譯，均待專業編輯與作者審閱。電影案例依據已發表評論作分析練習，未聲稱本書作者已觀看片段或核對時間碼。

<a id="CH07-S01"></a>
## 學習目標
完成本章後，讀者能：

1. 將角色可觀察的行動、目標、阻力和代價寫成可檢驗的因果鏈。
2. 區分人物資料、人物塑造（characterization）及角色在敘事中的功能；避免把人物簡化為性格標籤。
3. 為主要角色設計外在目標、內在需要或信念、策略與反策略，並指出這些選擇如何造成衝突。
4. 描述角色改變、拒絕改變或保持不變的弧線，並以行動和選擇作證，而非只用結尾台詞宣告。
5. 使用 AI 協助生成和比較角色方案，保留人類作者對因果、文化脈絡、表演可行性和倫理的決策權。

<a id="CH07-S02"></a>
## 先備知識
建議先讀 CH06「故事、情節與因果結構」，理解事件如何由角色行動與結果串連。無須預先採納「主角必須改變」或「每個角色都要有完整傳記」等創作規則；本章把它們視為可選策略，而非普遍定律。

## 核心術語
| TERM ID | 繁體中文 | English | 本章工作定義 |
|---|---|---|---|
| TERM-CH07-CHARACTER | 角色 | Character | 敘事中可被辨認並由身體、社會位置、行動、情緒、特質或思想等線索建構的人物。分析面向依作品需要選用，不等同完整真實人格。 |
| TERM-CH07-CHARACTERIZATION | 人物塑造 | Characterization | 作品透過行動、反應、外貌、聲音、關係與資訊安排，讓觀眾推論人物的過程。 |
| TERM-CH07-GOAL | 角色目標 | Character goal | 角色在特定情境中想取得、避免或完成的可表述結果；目標應能以行動與結果觀察。 |
| TERM-CH07-DESIRE | 欲望／戲劇需求 | Desire / dramatic need | 本章以「欲望」指角色推動行動的追求；引用 Syd Field 時保留其 dramatic need 用語，並說明 Field 將之界定為角色在劇本中想達成的事，避免把不同流派的 need 混為一談。 |
| TERM-CH07-OBSTACLE | 阻力 | Obstacle | 使目標不能直接達成的外在條件、他人意圖、制度限制或角色自身採取的策略。 |
| TERM-CH07-CONFLICT | 衝突 | Conflict | 互不相容的目標、價值或行動在具體情境中相遇，迫使角色選擇並造成可見後果。僅有爭吵或音量升高不必然形成有效戲劇衝突。 |
| TERM-CH07-CHARACTER-ARC | 角色弧線 | Character arc | 角色在故事過程中的信念、策略、關係或行動模式所呈現的變化；弧線亦可呈現退化、循環、拒絕改變或穩定，並非每種故事都要求正向成長。 |
| TERM-CH07-CHARACTER-AGENCY | 角色能動性 | Character agency | 角色在限制下作出選擇並影響後續事件的程度；受限不等於毫無能動性，應辨識結構性限制及選擇代價。 |

以上為編輯工作定義，均為 draft，來源與中譯仍待術語編輯核定。Bordwell 對人物建構的分析提示我們，可從身體、社會角色、行動能力、特質、情緒和思想等面向讀取人物；敘事也會安排人物重要性及彼此對照（R052）。Field 的戲劇需求用語是特定編劇方法，不應當成心理學診斷或唯一理論（R053）。

<a id="CH07-S04"></a>
## 歷史與基本原理
**理論脈絡。** Aristotle《詩學》討論悲劇的行動、情節與人物等構成；不同譯本對 ethos、praxis 等詞的翻譯和章節定位不完全相同。本章不把古典悲劇規範直接等同現代電影劇本規則；採用版次、譯名和頁碼待審（R046）。

**戲劇寫作實務傳統。** Lajos Egri 的《The Art of Dramatic Writing》以人物、前提與衝突作為戲劇寫作分析的重要組合。出版社書目與目錄可確認其相關章節包含 Character、Character Growth、The Antagonist、Conflict；本稿未以未核對的特定頁碼支持逐項操作建議（R054）。Syd Field 的公開問答把 dramatic need 說成角色想達成的事，並建議透過事件與場景顯現；此術語用法與其他創作流派所說的「內在需要」未必相同（R053）。

**電影敘事原理。** 人物不是只有背景設定。觀眾從有限線索推論其目標、情緒、特質及關係；行動若造成後果，人物也會進入因果鏈。角色層級、差異與相似性可協助觀眾辨識關係，但不能以固定原型取代具體行為分析（R052）。

**角色變化不是必備公式。** 弧線可以是改變、惡化、維持、循環或揭露觀眾先前不知道的面向。編劇可選擇用外在目標暴露內在信念，也可讓人物在不改變的情況下改變他人或社會情勢。這些是本書的實務分類，不宣稱是唯一公認模型。

<a id="CH07-S05"></a>
## 傳統電影製作方法
1. **角色訪談／人物檔案：** 先定義故事期間內會被看見的資訊：角色在此刻要什麼、害怕失去什麼、受什麼限制、願意付什麼代價。只有會影響選擇、表演或製作的背景才進入主檔；其餘放入研究筆記。
2. **目標與策略拆解：** 以動詞寫角色每場戲的策略，例如「說服」「拖延」「隱瞞」「測試」。策略要能演出或拍攝；抽象形容詞如「很勇敢」需轉成行動證據。
3. **關係網與對手設計：** 為重要角色記錄目標相容／衝突、依賴、權力差、共享資訊及關係變化。對手可以是人、制度、環境、時間或角色自身的選擇，不必設計成單純邪惡的反派。
4. **場景節拍與表演：** 編劇標出角色進場時的意圖、採取的策略、對方反應、策略轉換與離場狀態；導演與演員再依文本、排演、鏡位、剪接和聲音共同形成可見表演。不要把內心標籤直接當成演員指令。
5. **劇本修訂：** 檢查角色是否只因作者需要而突然知情、改變立場或犯錯；補足可理解的資訊取得、壓力、決策與代價。反應可以矛盾，但需讓觀眾有可辨認的線索。

<a id="CH07-S06"></a>
## AI 時代的技術轉換與限制
AI 可協助建立人物卡、列出互斥目標、提出場景策略變體、比對角色弧線前後狀態，或以結構化資料檢查角色名稱和知識狀態。它不能從短篇摘要可靠推知「真實心理」，也不能替代編劇對文化、階級、身心障礙、創傷、族群再現與表演倫理的判斷。生成結果可能把常見類型套路誤當自然因果，或令不同角色共享同一語氣。

**建議資料欄位（自訂 schema，不是業界標準）：** `character_id`、`story_role`、`public_goal`、`private_goal`、`belief_before`、`belief_after_or_unchanged`、`constraints`、`resources`、`relationships`、`knowledge_by_scene`、`strategies`、`costs`、`arc_evidence`、`open_questions`、`source_or_invention_status`。個人敏感資料不可直接送入未核准服務；若角色原型取材真人，先處理同意、匿名化與資料最小化。

**AI 工作假設：** 讓模型為同一角色生成多種互不相容的策略，再由作者依場景事實選擇，可能比要求模型直接「寫出立體角色」更容易驗收。這是待本專案實測的工作假設，非已證實模型能力。

<a id="CH07-S07"></a>
## 詳細工作流程
| 步驟 | 操作 | 產出與驗收 |
|---|---|---|
| 1. 定義戲劇範圍 | 寫下故事時間、敘事視角、角色在故事中的功能及主要情境。 | 每個主角都有明確故事範圍；不把未呈現的傳記當成既定事實。 |
| 2. 寫可觀察目標 | 用「角色＋行動＋對象／結果＋期限或條件」表述。 | 觀眾可從行動判斷進展，不只靠角色宣稱。 |
| 3. 列限制與代價 | 區分外在障礙、資源限制、制度壓力和角色自身採用的策略。 | 每項限制都能回到場景或世界設定；標出來源或示範假設。 |
| 4. 建立角色差異 | 比較主要人物的目標、方法、資訊、權力和價值排序。 | 至少存在一項具體相容、一項具體衝突；差異避免只落在外貌標籤。 |
| 5. 設計選擇節點 | 每個關鍵節點寫「可行選項、預期結果、實際代價」。 | 轉折由選擇或明確外力造成，不是無因轉向。 |
| 6. 描述弧線假設 | 比較開端／中段／結尾的信念、策略、關係和行為證據。 | 可判定變化、拒變或穩定；若沒有可見證據，標為待補而非宣稱弧線成立。 |
| 7. 編排場景行動 | 為每場戲寫角色意圖、策略、阻力、反應和結果。 | 情緒可多義，但場景行動和資訊流可被劇組理解。 |
| 8. 使用 AI 比較版本 | 只提供必要且不敏感的故事資訊，要求模型輸出限定欄位、不同方案及理由。 | 保留提示詞、模型／版本（若可得）、日期、人工選擇與拒絕方案。 |
| 9. 排演／桌讀 | 讓演員以可演動詞執行；記錄台詞、停頓、動作和關係理解上的問題。 | 不把生成器輸出當作演員表演命令；由導演與演員共同調整。 |
| 10. 修訂與追蹤 | 把採納的選擇回寫到分場、劇本及角色知識表。 | 修訂前後差異可追溯；檢查其他場次的連鎖影響。 |

## 提示詞與技術參數
以下是模型中立的**示範模板**，不是任何供應商的已測功能或固定參數。無通用的溫度、token 數或最佳模型設定；需依實際工具版本和作品測試紀錄。

```text
任務：分析下方虛構故事中的角色行動因果，不替作者決定正史。
輸入：故事前提、角色在本場戲已知資訊、場景目標、限制、前一場結果。
請輸出 JSON 陣列，每個方案包含：
  character_id, immediate_goal, strategy (可演動詞), obstacle,
  choice, likely_consequence, what_must_be_true, stereotype_risk,
  evidence_from_input, uncertainties。
限制：提出 3 個彼此不同但符合已知資訊的方案；不得新增人物歷史作為事實。
每個推論標示「文本明示／推論／新創提案」。不得輸出敏感真人資料。
```

驗收：JSON 可解析；ID 合法；未出現輸入中沒有的故事事實而未標示創作；三方案的策略確有差異；角色行動前後資訊一致；編劇記錄採納、改寫或拒絕原因。不得只用「更有層次」或「更有共鳴」等不可測字眼評分。

## 案例分析：角色如何由目標與行動被讀取
以下是基於具名評論與電影敘事研究的**二手資料案例**；未記錄本書作者觀看版本或 timecode，因此不作逐鏡頭觀察或版本比較。

### 案例 A｜《House of Games》（David Mamet, 1987）

Criterion Collection 刊載的 Shonni Enelow 評論指出，該片表演方法可由場景中的具體行動目標來理解，並分析 Dr. Margaret Ford 的防衛姿態、失控與重新主張自我的變化。此處應標明為評論者的詮釋，而非唯一讀法。教學拆解：先將「她很冷」改寫成可見行為，再問她當場想影響誰、使用何策略、對方如何回應，以及後段行動是否改變我們對她的推論（R055）。

**練習轉化：** 不複製電影人物或場景。另寫一位有專業權威的角色，在公共場合試圖控制對話；設計一個對方反應令其原策略失效的選擇點。

### 案例 B｜《The Power of the Dog》（Jane Campion, 2021）

Amy Taubin 的 Criterion 評論指出，片頭旁白提出「何謂男人」及保護母親的問題，並把它視為貫穿全片的戲劇張力；她也分析角色關係、社會化男性氣質和情節結局。這些是評論者對電影的解讀，不能簡化成角色的唯一心理診斷（R056）。教學拆解：把角色的自我宣稱、社會規範、可見行動和他人回應分欄；檢查觀眾何時得到支持或反證，避免將暴力或沉默當作單一性格標籤。

**練習轉化：** 以全新人物、文化環境和具體物件，寫一段「角色如何理解某種身份要求」的場景；不能仿用原片的家庭關係、牧場設定、台詞或視覺設計。

### 案例 C｜人物資訊面向與層級

Bordwell 在〈Three Dimensions of Film Narrative〉說明，電影人物可透過身體、社會角色、可自主行動、特質、情緒與思想等線索被建構，並討論人物層級及相互對照。這套分析框架可用於閱讀人物資訊如何分配；不是要求每個角色都填滿所有欄位（R052，章節 “Three Dimensions of Film Narrative,” printed pp. 31–32；本次查閱作者公開 PDF 頁面，使用頁碼依該 PDF 印刷頁碼，正式引用前仍須核對採用版）。

## 常見錯誤與品質檢查
| 錯誤 | 為何有問題 | 檢查／修正 |
|---|---|---|
| 把欲望、need、目標當同義詞 | 不同理論和編劇教材定義不同。 | 每次引用標明來源用語；本章將 Field 的 dramatic need 和其他流派的內在 need 分開。 |
| 用「勇敢、善良、瘋狂」取代行動 | 標籤不能直接排演或驗證，還可能固化偏見。 | 以具體場景行動、反應及後果支持人物推論。 |
| 主角沒有能動性 | 劇情看似由作者任意推動。 | 檢查角色是否能選擇、拒絕、延遲、誤判或改變策略；若結構限制選項，呈現其機制。 |
| 衝突只靠誤會或資訊隱瞞 | 解開資訊後衝突可能立即消失，且人物行為顯得造作。 | 問即使所有人知道事實，目標或價值是否仍不相容。 |
| 強迫正向弧線 | 把特定文化的成長觀念當成普遍公式。 | 明列作品選用的弧線型態及其主題代價；穩定或悲劇性弧線同樣可成立。 |
| 背景故事過量 | 傳記細節未轉化為當下選擇，佔用劇本篇幅。 | 每筆設定標記「在故事內呈現／僅作者備忘」及其因果用途。 |
| AI 讓角色聲音同質化 | 模型可能重用常見句型、套路或刻板印象。 | 角色分開桌讀；用語料內對照、人物目標與語用策略驗證，不以口音拼寫作差異。 |
| 將創傷、疾病或身分當劇情捷徑 | 可能污名化或造成缺乏脈絡的再現。 | 由相關經驗者／專業顧問審查；說明研究依據與敘事責任。 |

機器可查：欄位完整、JSON schema、角色 ID、名稱一致、每場戲有目標與結果、引用 ID 存在。人類需查：行動可信度、表演含義、文化刻板印象、情感效果及弧線是否有說服力。機器測試通過不代表人物塑造成功。

<a id="CH07-S11"></a>
## 練習、評量與延伸研究
### 練習 1｜目標—策略—代價

自創一個不超過 150 字的情境，讓角色想取得一件日常但重要的物品。列出目標、兩種策略、阻力、對方目標、角色作出的選擇及代價。評量重點：目標可觀察（0–2）、衝突非單純爭吵（0–2）、選擇造成可追因果結果（0–2）、未把推論冒充背景事實（0–2）。

### 練習 2｜弧線證據表

為一位自創角色寫故事開端、中段、結尾各一個可拍攝行動，並填入其信念、策略和關係。最後判定是變化、退化、循環、拒變或暫不確定，附上證據。不得僅以「學會了愛」作為結論。

### 練習 3｜AI 方案比較

將同一場戲交給本地或已獲授權的模型產生三個策略方案；不使用付費服務，除非帳戶與預算另獲作者授權。保留輸入、輸出、日期、模型版本、篩選依據；評估是否符合已知資訊、是否彼此不同、是否新增未標記事實及是否含偏見。

**延伸研究：** 比較角色行動與敘事因果的理論、表演方法如何改變觀眾對角色的歸因、群像角色層級如何影響資訊分配，以及 AI 生成文本的角色一致性評測。避免把計算模型的可測變項直接當作觀眾心理或藝術價值的完整描述。

## 結語
