# 引用與證據規範

優先使用電影理論／史料的學術出版社、期刊、檔案館及原始文獻；AI 工具功能優先官方文件、版本紀錄及可重現實測。每筆來源使用永久 `R###`，記錄作者／機構、年份、標題、出版資訊、DOI／穩定 URL、存取日、版本、支持的主張與查證狀態。引用頁碼僅在核對原件後填寫。

主張標籤：`verified-fact`（可追溯事實）、`theory`（標明理論脈絡）、`practice`（實務建議）、`ai-hypothesis`（待驗證 AI 推論）、`demo`（示範內容）。不可捏造引文、史料、論文、頁碼、URL 或工具能力。時效資訊記錄查證日期及文件／產品版本；失效連結保留記錄並更新替代來源。
