# V2 圖片原創、來源與權利規範

正式出版圖片必須為本專案原創，或有文件化授權。網路搜尋圖片僅供研究參考，禁止直接下載或嵌入正式出版物。不得描摹或高度仿作第三方作品。

每個永久 `figure_id` 必須記錄教學目的、段落位置、研究來源與查證日期、原創 prompt／繪圖方法、生成工具與版本、製作修改紀錄、權利／技術／編輯審查、繁中與英文圖說及 alt。AI 生成不代表已取得排他著作權；肖像、商標、受保護作品另行審查。

原圖放 `originals/`，核准底圖放 `approved/`，文字標註保存在可編輯 `overlays/*.svg`，輸出版放 `exports/`。原始生成圖避免烘焙大量文字，雙語標籤應可編輯。缺圖只建立 figure brief／待辦，不以網圖填補。正式發佈需三項審查全數 approved；未核准圖不得輸出。
