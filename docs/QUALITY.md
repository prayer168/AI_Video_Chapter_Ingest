# 品質審查規則

## 主張標籤

章節需清楚區分下列類別：

- **已查證事實**：可由列出的可靠來源直接支持，附定位資訊。
- **電影理論**：指出理論家、概念來源、適用脈絡及主要爭議／限制。
- **實務建議**：說明適用情境、目標與權衡，不宣稱為普遍唯一做法。
- **AI 生成假設**：模型產生且尚未獨立證實的內容，明確標示並要求覆核。
- **示範內容**：為教學而編作的鏡頭、提示詞、數值或案例；不得冒充真實片場紀錄。

## 章節審查關卡

### 內容與電影知識

- 學習目標可觀察，先備知識與章節難度相符。
- 史實、理論、實務建議與示範內容有明確區分。
- 專業名詞中英對照一致，並使用 `data/terms.yaml` 的 canonical ID。
- 案例含作品版本資訊；鏡頭分析把畫面觀察與詮釋分開。
- 傳統流程與 AI 工作流均說明輸入、步驟、輸出、人工決策和限制。

### AI 與技術

- 工具能力以官方文件和可重現實測支持，含版本、日期、參數與限制。
- 不臆測模型內部機制、未公開參數、訓練資料或產品功能。
- 提示詞案例說明工具、輸入素材、輸出條件、迭代與驗收方法。
- 檢查隱私、偏誤、來源追蹤、權利、揭露與人類覆核。

### 來源與出版

- 每項可驗證主張有來源 ID；引用指向實際支持該主張的來源。
- DOI、URL、版本、頁碼及日期不可臆造；不確定欄位留空並註明。
- 外部連結檢查結果經人工解讀；線上不可達不等於來源無效。
- Markdown 可解析，metadata 有效，術語與來源 ID 可解析。
- HTML 語意結構完整；DOCX/PDF 產物可開啟，PDF 字型嵌入須核對。

## 發佈狀態

- `planned`：只有規劃。
- `draft`：有正文但尚未完成來源與編輯審查。
- `review`：作者初審完成，待獨立審閱。
- `verified`：來源、技術和文字檢核完成；仍可能因新證據更新。

自動檢查只驗證格式與可解析性，不能將章節自動升為 `verified`。
