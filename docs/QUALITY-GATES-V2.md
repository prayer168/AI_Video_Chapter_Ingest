# V2 品質審查規則

## 阻擋條件
- 章節 ID、locale、永久錨點重複或缺漏；zh/en 配對不一致。
- 參考 ID 未登錄、必要來源欄位缺漏、外部連結失效（網路檢查可選，離線標示未檢）。
- 正式輸出含無核准圖片、外部圖片 URL、缺雙語 alt/caption、未記錄權利／版本。
- PDF 字型未嵌入或繁中文字形渲染未人工抽查；未經人工校樣不得宣稱出版就緒。
- 英文稿非人工審校卻標記 approved；源稿變更後仍維持譯文 approved。

## 審查分類
1. 結構：metadata、錨點、交叉引用、雙語狀態。
2. 證據：來源可追溯、主張類型清楚、版本及日期充分。
3. 專業：電影概念、技術參數、工作流程由專業審查者複核。
4. 圖像：權利、技術、編輯核准；向量圖可編輯且術語正確。
5. 出版：HTML/DOCX/PDF/EPUB 產物檢查、字型嵌入、溢版、孤行寡行及連結。

任何未實測功能、待查主張、生成假設均須明確標示，不能以 CI 通過取代編輯與專業審讀。
