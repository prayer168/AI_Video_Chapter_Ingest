# 中英翻譯管理

`content/zh-TW` 為創作主稿；`content/en-US` 為人工審校譯稿。兩語共用永久章節、段落、術語、引用及圖號 ID。章名、slug 可各語系呈現，但 ID 不變。

狀態：`source-draft`、`review-needed`、`approved`、`out-of-sync`、`translation-needed`。源稿變更時使已核准譯文失效並標記 out-of-sync。逐節核對技術術語、引文頁碼、單位和提示詞參數；記錄譯者、編輯、來源 revision、審查日期及疑義。不得以即時機器翻譯當成正式英文稿。網站缺譯顯示明確缺譯標記，不回退顯示錯語言內容。
