# CH09 人工審查清單

所有項目初始狀態均為 **NEEDS HUMAN REVIEW**；依使用者安排，待全書內容完成後集中簽核。

- [ ] 作者：確認章名、論點、範例與本書編輯立場。
- [ ] 電影理論編輯：核對 Altman、Mittell、Bordwell 與 plotline 研究的採用版本、完整頁碼／段落定位與詮釋範圍。
- [ ] 案例審查者：記錄《Memento》《Dunkirk》《The Wire》的合法可用版本、集／場景／時間碼；確認案例分析與來源相符。
- [ ] 雙語編輯：校訂全文、專有名詞、段落對照與圖說；核准九個術語偏好譯名。
- [ ] 插圖審查者：核對三張 SVG 的視覺可讀性、行動裝置顯示、對比、alt text 與圖說；確認創作者署名及授權。
- [ ] 出版編輯：逐頁審 DOCX、PDF、EPUB，檢查目錄、圖號、換頁、字型及雙語標點。
- [ ] 作者簽核：僅在以上完成後核准 publication-ready。

簽核前不得將 `approval_status` 或 `publication_status` 改為已核准。
